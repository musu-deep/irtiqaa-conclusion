# ERTIQA Observatory - Desktop Build Ready

هذه حزمة جاهزة لتحويل منصة ارتقاء إلى تطبيق مكتبي مستقل.

## الخيار السريع
- شغّل `RUN_DESKTOP.bat`
- ستفتح المنصة داخل نافذة Desktop مباشرة

## إنشاء ملف EXE
- شغّل `BUILD_EXE.bat`
- بعد اكتمال البناء ستجد الملف هنا:
  `dist\ERTIQA_Observatory\ERTIQA_Observatory.exe`

## المتطلبات
- Windows
- Python 3.10 أو أحدث

## ملاحظات
- هذه الحزمة تفصل ارتقاء بصريًا وتشغيليًا عن مشروع أراك
- التطبيق يشغّل خادمًا محليًا داخليًا ثم يفتحه داخل نافذة Desktop
- إذا كان المنفذ 8027 مستخدمًا سيختار منفذًا قريبًا تلقائيًا
